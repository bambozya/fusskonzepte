# fusskonzepte

Website fuer fusskonzepte GmbH in Bad Segeberg.

Die Website informiert ueber orthopaedische Schuhtechnik, individuelle Einlagen, Diabetikerversorgungen, Schuhzurichtungen und Reparaturen.

## Website

[https://bambozya.github.io/fusskonzepte](https://bambozya.github.io/fusskonzepte)

## Lokal ausfuehren

Da es sich um eine statische Website handelt, kann `index.html` direkt im Browser geoeffnet werden. Fuer einen lokalen Server:

```sh
python3 -m http.server 8000
```

Danach ist die Website unter [http://localhost:8000](http://localhost:8000) erreichbar.
